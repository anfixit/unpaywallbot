# Support

Unpaywall Bot is a volunteer-maintained experimental project. Support is provided on a best-effort basis.

## Before asking

1. Read `README.md` or `README.ru.md`.
2. Check `docs/DEPLOYMENT.md` for deployment questions.
3. Search existing issues and pull requests.
4. Run the current `main` revision with the committed `uv.lock`.
5. Collect logs with secrets and personal data removed.

## Where to ask

- Use a GitHub issue for a reproducible bug.
- Use GitHub Discussions for general questions when Discussions are enabled.
- Use a pull request for a tested fix.
- Follow `SECURITY.md` for vulnerabilities. Never report them publicly.

## Bug report information

Include:

- operating system and architecture
- Python, uv, Docker, and Docker Compose versions
- commit SHA or release tag
- redacted environment settings
- exact command used
- expected and actual behavior
- minimal logs and traceback
- a public test URL only when sharing it is lawful and necessary

Do not include:

- Telegram tokens
- SSH keys
- GitHub tokens
- cookies or passwords
- private server addresses
- subscriber-only article text
- raw user identifiers

## Compatibility reports

A site changing its HTML or blocking a request is not automatically a security incident. Open a normal bug report with a public URL and a minimal description. Compatibility is not guaranteed for any publication.

## Unsupported requests

The project does not provide help with:

- unauthorized access to paid or private content
- CAPTCHA, DRM, or account entitlement bypass
- credential sharing
- attacking or scanning third-party infrastructure
- hiding malicious traffic
